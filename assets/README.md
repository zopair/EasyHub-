# Assets

Place project-owned visual assets here, such as an optimized product demo GIF, logo, or screenshots.

- Use assets that the project has permission to distribute.
- Keep images reasonably small so the repository and Pages site remain fast.
- Provide descriptive alternative text when images are embedded in documentation.
- Do not add `easyhub-demo.gif`, a logo, or screenshots until the actual asset exists and has been reviewed.

The current product demo is linked from the main README and hosted on Google Drive.
