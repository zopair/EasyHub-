# EasyHub

**Intent, resolved.** اكتب ما تريد تحقيقه، وسيبحث EasyHub مباشرةً في GitHub عن مشروعات مفتوحة المصدر مناسبة.

## الاستضافة والتشغيل

- **الواجهة:** GitHub Pages — موقع ثابت، دون خادم أو خدمة استضافة خارجية.
- **البحث:** GitHub REST API من المتصفح مباشرةً؛ لا يوجد backend أو وسيط خاص.
- **النشر:** GitHub Actions ينشر الموقع تلقائيًا عند كل `push` إلى `main`.
- **المصدر:** https://github.com/zopair/EasyHub-
- **رابط Pages المتوقع:** https://zopair.github.io/EasyHub-/

> ملاحظة: يجب ضبط Pages مرة واحدة من إعدادات المستودع على **Settings → Pages → Build and deployment → Source: GitHub Actions** إذا لم يكن مفعّلًا بالفعل. بعد ذلك تتم عمليات النشر تلقائيًا من workflow. حالة التشغيل الفعلية تظهر في تبويب Actions.

## المزايا

- واجهة عربية RTL، متجاوبة مع الهاتف، بتصميم dark cyberpunk/glassmorphism.
- بحث مباشر عبر GitHub API، دون رمز وصول أو مفاتيح سرية داخل المتصفح.
- ترتيب تقريبي حسب تطابق الكلمات ولغة البرمجة والنجوم.
- عرض النتائج التي يذكر GitHub لها ترخيصًا معروفًا من القائمة المسموح بها: MIT، Apache-2.0، BSD-2-Clause، BSD-3-Clause، ISC، 0BSD، Unlicense، CC0-1.0.
- لا يتم تنزيل أو تشغيل كود المستودعات تلقائيًا.

## قيود مهمة

- **GitHub Pages استضافة ثابتة فقط:** لا يشغّل Python أو API خلفيًا. البحث ينفّذ من المتصفح إلى GitHub API مباشرةً.
- البحث العام غير المصادق عليه محدود بحصص GitHub API، وقد تظهر رسالة انتظار عند بلوغ الحد. لا يوجد مفتاح مخفي أو خدمة مدفوعة تتجاوز هذا القيد.
- ظهور ترخيص في بيانات GitHub ليس مراجعة قانونية أو ضمانًا لصحة كل ملف داخل المستودع. راجع الترخيص الفعلي واعتماديات المشروع قبل استخدامه.
- نسب التوافق تقديرات إرشادية وليست احتمالات دقيقة أو شهادة جودة.

## التطوير المحلي

يمكن فتح `index.html` مباشرةً في المتصفح أو تشغيل خادم ثابت محلي:

```bash
python -m http.server 8080
```

لا توجد اعتماديات تشغيلية أو عملية بناء مطلوبة للموقع.

## الأمان والترخيص

- لا تحفظ رموز GitHub أو أي أسرار في كود الواجهة.
- أسماء المستودعات والأوصاف والروابط محتوى خارجي غير موثوق.
- كود EasyHub الأصلي مرخّص بموجب MIT (انظر `LICENSE`). لا يعيد ذلك ترخيص مشروعات الطرف الثالث؛ لكل مشروع ترخيصه الخاص.
- ملفات إعداد Vercel وواجهة Python الخلفية أزيلت ضمن الانتقال إلى GitHub Pages.
